# Student Club Management System

## Description

A beginner Python project that manages student groups using Set operations.

## Concepts Used

- Python Sets
- Union operation (|)
- Intersection operation (&)
- Difference operation (-)
- Membership checking (in)
- User input
- Conditional statements

## Features

- Find students in both clubs
- Find students only in Python club
- Check student membership

## Example

Python Club:
Ali, Ahmed, Sara, John

Web Club:
Ahmed, Sara, Mike, Emma

Common Students:
